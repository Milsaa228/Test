# Проекты

Общий репозиторий проектов, созданных с Claude Code. Каждый проект лежит в своей папке и имеет собственный README.

| Папка | Описание | Стек |
|---|---|---|
| [`tbank-expenses`](tbank-expenses/) | Мобильное приложение для статистики расходов по данным Т-Банка (импорт CSV-выписки, Т-Бизнес API) | Expo / React Native, TypeScript |
| [`tab-audio-recorder`](tab-audio-recorder/) | Расширение для браузера: запись звука вкладки в файл и сохранение играющих треков (Chrome/Edge, частично Android) | JavaScript, Chrome Extension MV3 |
