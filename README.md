# Проекты

Общий репозиторий проектов, созданных с Claude Code. Каждый проект лежит в своей папке и имеет собственный README.

| Папка | Описание | Стек |
|---|---|---|
| [`tbank-expenses`](tbank-expenses/) | Статистика расходов по данным Т-Банка (импорт CSV-выписки, Т-Бизнес API) и «Двойник»: прогноз до зарплаты, подписки, чат с нейросетью о финансах | Expo / React Native, TypeScript, OpenRouter (бесплатно) |
| [`split-bill`](split-bill/) | Делёжка счёта: фото чека → нейросеть разбирает позиции → кто что ел → сообщение друзьям с суммами | Expo / React Native, TypeScript, OpenRouter (бесплатно) |
| [`fridge-chef`](fridge-chef/) | Холодильник-шеф: продукты по фото, сроки годности с напоминаниями, рецепты из того, что есть | Expo / React Native, TypeScript, OpenRouter (бесплатно) |
| [`geo-notes`](geo-notes/) | Гео-заметки: заметка, привязанная к месту, всплывает, когда вы рядом; обмен заметками ссылкой | Expo / React Native, TypeScript, expo-location, OpenStreetMap |

## Установка на Android (без компьютера)

1. Откройте на телефоне https://github.com/Milsaa228/Test/releases/tag/apk
2. Скачайте нужный `.apk` (split-bill, fridge-chef, geo-notes, tbank-expenses) и откройте его.
3. Android попросит разрешить установку из браузера — разрешите. Новые версии ставятся поверх старых, данные сохраняются.

APK собираются автоматически в GitHub Actions после каждого изменения кода приложения (около 15–20 минут).
Ход сборки — на вкладке Actions репозитория.

## Нейросеть

Распознавание чеков и продуктов, рецепты и чат «Двойника» работают на бесплатных моделях OpenRouter.
Ключ бесплатный: openrouter.ai → войти через Google/GitHub → Keys → Create key, затем вставить в настройках приложения.
Лимит — около 50 запросов в день и 20 в минуту на аккаунт. Ключ хранится только на телефоне.
