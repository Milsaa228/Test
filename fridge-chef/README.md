# Холодильник-шеф

Мобильное приложение (Expo / React Native, iOS и Android): фотографируете холодильник, нейросеть распознаёт продукты,
приложение следит за сроками годности и подсказывает, что приготовить из того, что скоро испортится.

## Возможности

- **Фото → продукты.** До 3 фото за раз (камера или галерея): нейросеть определяет название, примерное количество,
  категорию и сколько дней продукт ещё пролежит. Сроки можно поправить до сохранения.
- **Мои продукты.** Список по сроку годности, подсветка «скоро испортится» (≤ 2 дней) и просроченного.
  Ручное добавление и редактирование: количество, единицы, категория, дата добавления и «годен до».
  Кнопки «Использовал» (для штучного — минус одна штука) и «Удалить».
- **Без дублей.** Повторное фото того же холодильника не задваивает продукты (сравнение по названию без учёта
  регистра, ё/е и пунктуации): обновляется только количество, срок годности остаётся прежним.
- **Что приготовить?** Нейросеть получает список продуктов (скоро портящиеся — в приоритете) и ваши предпочтения:
  питание, исключения и аллергии, время готовки, число порций. В ответ — 3–5 рецептов: время, сложность,
  какие продукты уходят, чего не хватает, шаги.
- **«Приготовил»** списывает продукты рецепта: совместимые единицы вычитаются (300 мл из 1 л), остальное убирается.
- **Избранные рецепты** и последняя подборка сохраняются на устройстве.
- **Утреннее напоминание** в 9:00 о продуктах, которые испортятся завтра (локальное уведомление, если разрешено).
  В браузере уведомлений нет — вместо них баннер на экране продуктов.
- Данные хранятся только на устройстве: продукты и рецепты в AsyncStorage, ключ API в Keychain/Keystore (expo-secure-store).
- **Бесплатно.** Работает на бесплатных моделях OpenRouter — платный API не нужен.

## Запуск

```bash
npm install
npx expo start          # открыть в Expo Go (QR-код) или в эмуляторе
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: сроки годности, слияние продуктов, списание, разбор ответов нейросети
```

Перед первым распознаванием вставьте бесплатный ключ OpenRouter (`sk-or-…`) на вкладке «Настройки»
(как его получить — ниже).

Сборка для установки на телефон: `npx eas-cli@latest build -p android --profile preview` (или `-p ios`).

## Структура

```
src/app/            экраны (Expo Router): _layout (стек), (tabs)/_layout (вкладки),
                    (tabs)/index (мои продукты), (tabs)/recipes, (tabs)/settings,
                    scan (фото → продукты), product (добавить/изменить), recipe/[id]
src/components/     тема, общие кнопки, пустые состояния, notify/confirm
src/context/        DataContext: продукты, рецепты, настройки, ключ API
src/lib/            ai (клиент OpenAI-совместимого API, бесплатные модели), fridge (распознавание фото), recipes (подбор рецептов),
                    inventory (слияние, списание, единицы), expiry (сроки, уведомление),
                    photos (камера/галерея, уменьшение фото), notifications, storage, types
scripts/test.mjs    тесты на node:test
```

## Нейросеть: бесплатный ключ OpenRouter

Распознавание фото и подбор рецептов работают через бесплатные модели [OpenRouter](https://openrouter.ai)
(модели с пометкой `:free`). Платить ничего не нужно, карта не нужна.

**Как получить ключ прямо с телефона:**

1. Откройте в браузере https://openrouter.ai/settings/keys (или в приложении: «Настройки» → «Получить ключ на openrouter.ai»).
2. Войдите через Google или GitHub (или по почте).
3. Нажмите **Create key**, введите любое название, лимит оставьте пустым → **Create**.
4. Скопируйте ключ (`sk-or-v1-…`, показывается один раз) и вставьте его в приложении на вкладке «Настройки» → «Сохранить ключ».

**Ограничения бесплатных моделей:**

- около **50 запросов в день** на аккаунт (одно распознавание или одна подборка рецептов — 1–3 запроса)
  и до **20 запросов в минуту**; при превышении приложение покажет «Лимит бесплатных запросов исчерпан»;
- если пополнить баланс OpenRouter хотя бы на $10, дневной лимит бесплатных моделей вырастает до 1000;
- бесплатные модели слабее платных и отвечают медленнее: иногда пропускают продукты или ошибаются в количестве —
  проверяйте результат перед сохранением.

**Как выбирается модель.** По умолчанию модель `auto`: приложение берёт каталог OpenRouter и выбирает бесплатные
модели — для фото только те, что понимают картинки, для рецептов (картинки не отправляются) подходит любая.
Если модель перегружена или вернула мусор, запрос автоматически повторяется на следующей (до 3 попыток).
Формат ответа описан в промпте примером JSON, а ответ разбирается терпимо: числа строками, пропущенные поля,
лишний текст или markdown вокруг JSON не ломают приложение.

**Для продвинутых.** В «Настройки» → «Для продвинутых: другой API или модель» можно указать любой
OpenAI-совместимый API (`/chat/completions`): адрес (например, `https://api.groq.com/openai/v1` или локальный
Ollama `http://192.168.1.10:11434/v1` — ключ любой), ключ и конкретную модель (например, `google/gemma-3-27b-it:free`).
Для API, отличных от OpenRouter, модель нужно указать вручную; для распознавания фото она должна понимать картинки.

## Замечания по ключу API

- Ключ вводит сам пользователь, он хранится только на устройстве (на web — в localStorage браузера,
  потому что SecureStore там недоступен).
- Запросы идут напрямую из приложения на `openrouter.ai` (или на указанный вами API).
  Фото перед отправкой уменьшаются до ~1568 px по длинной стороне и сжимаются в JPEG.
- Для продакшена лучше свой бэкенд-прокси: ключ останется на сервере, а не в приложении у каждого пользователя,
  и можно будет ограничить частоту запросов.
- Сроки годности — оценка нейросети по типичному сроку хранения, а не по дате на упаковке. Проверяйте их.
