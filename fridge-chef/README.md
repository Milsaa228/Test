# Холодильник-шеф

Мобильное приложение (Expo / React Native, iOS и Android): фотографируете холодильник, Claude распознаёт продукты,
приложение следит за сроками годности и подсказывает, что приготовить из того, что скоро испортится.

## Возможности

- **Фото → продукты.** До 3 фото за раз (камера или галерея): Claude определяет название, примерное количество,
  категорию и сколько дней продукт ещё пролежит. Сроки можно поправить до сохранения.
- **Мои продукты.** Список по сроку годности, подсветка «скоро испортится» (≤ 2 дней) и просроченного.
  Ручное добавление и редактирование: количество, единицы, категория, дата добавления и «годен до».
  Кнопки «Использовал» (для штучного — минус одна штука) и «Удалить».
- **Без дублей.** Повторное фото того же холодильника не задваивает продукты (сравнение по названию без учёта
  регистра, ё/е и пунктуации): обновляется только количество, срок годности остаётся прежним.
- **Что приготовить?** Claude получает список продуктов (скоро портящиеся — в приоритете) и ваши предпочтения:
  питание, исключения и аллергии, время готовки, число порций. В ответ — 3–5 рецептов: время, сложность,
  какие продукты уходят, чего не хватает, шаги.
- **«Приготовил»** списывает продукты рецепта: совместимые единицы вычитаются (300 мл из 1 л), остальное убирается.
- **Избранные рецепты** и последняя подборка сохраняются на устройстве.
- **Утреннее напоминание** в 9:00 о продуктах, которые испортятся завтра (локальное уведомление, если разрешено).
  В браузере уведомлений нет — вместо них баннер на экране продуктов.
- Данные хранятся только на устройстве: продукты и рецепты в AsyncStorage, ключ API в Keychain/Keystore (expo-secure-store).

## Запуск

```bash
npm install
npx expo start          # открыть в Expo Go (QR-код) или в эмуляторе
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: сроки годности, слияние продуктов, списание, разбор ответов Claude
```

Перед первым распознаванием вставьте свой ключ Anthropic API (`sk-ant-…`) на вкладке «Настройки».
Ключ создаётся на https://console.anthropic.com/settings/keys.

Сборка для установки на телефон: `npx eas-cli@latest build -p android --profile preview` (или `-p ios`).

## Структура

```
src/app/            экраны (Expo Router): _layout (стек), (tabs)/_layout (вкладки),
                    (tabs)/index (мои продукты), (tabs)/recipes, (tabs)/settings,
                    scan (фото → продукты), product (добавить/изменить), recipe/[id]
src/components/     тема, общие кнопки, пустые состояния, notify/confirm
src/context/        DataContext: продукты, рецепты, настройки, ключ API
src/lib/            claude (клиент Claude API), fridge (распознавание фото), recipes (подбор рецептов),
                    inventory (слияние, списание, единицы), expiry (сроки, уведомление),
                    photos (камера/галерея, уменьшение фото), notifications, storage, types
scripts/test.mjs    тесты на node:test
```

## Замечания по ключу API

- Ключ вводит сам пользователь, он хранится только на устройстве (на web — в localStorage браузера,
  потому что SecureStore там недоступен).
- Запросы идут напрямую из приложения на `api.anthropic.com` (модель `claude-opus-5-5`, ответ — JSON по схеме).
  Фото перед отправкой уменьшаются до ~1568 px по длинной стороне и сжимаются в JPEG.
- Для продакшена лучше свой бэкенд-прокси: ключ останется на сервере, а не в приложении у каждого пользователя,
  и можно будет ограничить расходы и частоту запросов.
- Сроки годности — оценка Claude по типичному сроку хранения, а не по дате на упаковке. Проверяйте их.
