# Гео-заметки

Мобильное приложение (Expo / React Native, iOS и Android) для заметок, привязанных к месту: «тут лучшая шаурма»,
«код домофона 1234», «купить молоко в этом магазине». Заметка всплывает, когда вы оказываетесь рядом.

## Возможности

- Заметка: текст, эмодзи-категория, радиус 50 / 100 / 300 м, режим «Каждый раз» или «Один раз».
- Место — где вы сейчас или любая точка: удерживайте палец на карте (вкладка «Карта») или коснитесь карты в форме заметки.
- Карта со всеми заметками, зонами срабатывания и вашей позицией. Нажатие на маркер открывает заметку.
- Список «Рядом», отсортированный по расстоянию, с подписями «≈ 120 м» и отметкой «вы здесь».
- Карточка заметки: изменить, удалить, поделиться, открыть в Яндекс Картах или другом приложении карт
  (`geo:` на Android, Apple Maps на iOS), «Напомнить снова» для сработавших одноразовых.
- Напоминания: пока приложение открыто, оно следит за позицией. При входе в зону заметки появляются баннер в приложении
  и локальное уведомление. Нажатие на уведомление открывает заметку.
  - Срабатывает только вход в зону (снаружи → внутри). Если вы стоите на месте, повторов не будет.
  - Пауза между повторами одной заметки: 15 мин, 1 ч, 6 ч или 24 ч (в настройках).
  - Режим «Один раз» напоминает только при первом приближении.
  - Граница зоны с запасом (+20% радиуса, минимум 20 м), чтобы дрожание GPS не давало «вошёл-вышел-вошёл».
    Позиции с точностью хуже 250 м не учитываются.
  - Заметка, созданная там, где вы стоите, не срабатывает сразу.
- Фоновый режим (переключатель в настройках): системные геозоны (`expo-location` `startGeofencingAsync` +
  `expo-task-manager`) для 20 ближайших заметок. Напоминают, даже когда приложение закрыто.
- Обмен с друзьями без сервера: «Поделиться» отправляет текст с ссылкой на Яндекс Карты и ссылкой
  `geonotes://import?data=<base64url JSON>`. При открытии ссылки появляется экран подтверждения.
  Заметки добавляются без дублей (по `id`, локальная версия главнее). Ссылку или весь текст сообщения можно вставить
  вручную: «Настройки» → «Импорт по ссылке».
- Объяснения на русском, если геолокация не разрешена, запрещена навсегда (кнопка «Открыть настройки») или недоступна.
- Данные хранятся только на устройстве (AsyncStorage).

## Запуск

```bash
npm install
npx expo start          # открыть в Expo Go (QR-код) или в эмуляторе
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: расстояния, срабатывания и паузы, геозоны, ссылки для обмена
```

Сборка для установки на телефон: `npx eas-cli@latest build -p android --profile preview` (или `-p ios`).

## Expo Go и development build

| Функция | Expo Go | Development build |
|---|---|---|
| Карта, заметки, список, обмен ссылкой (вставка вручную) | да | да |
| Слежение за позицией при открытом приложении, баннер, локальные уведомления | да | да |
| Открытие ссылок `geonotes://` из мессенджера | нет: у Expo Go своя схема `exp://` | да |
| Фоновый режим (геозоны при закрытом приложении) | нет: переключатель недоступен | да |

Development build: `npx expo run:ios` / `npx expo run:android` локально или
`npx eas-cli@latest build --profile development`. Разрешения уже настроены в `app.json`: строки
`NSLocation*UsageDescription`, `UIBackgroundModes: location` на iOS и `ACCESS_BACKGROUND_LOCATION` на Android
(через плагин `expo-location`). Для фонового режима система попросит доступ «Всегда» / «Разрешить в любом режиме».

Карта — OpenStreetMap через Leaflet (`react-native-webview`), ключи API не нужны. Для карты нужен интернет:
Leaflet (`unpkg.com`, версия закреплена, с проверкой целостности SRI) и тайлы (`tile.openstreetmap.org`) загружаются
из сети. Без сети вместо карты появится сообщение и кнопка «Повторить»; заметки и напоминания работают и без карты.

В браузере (`npx expo start --web`) карты нет: вместо неё список заметок и ввод координат. Локальных уведомлений
и фонового режима тоже нет, работает только баннер.

## Структура

```
src/app/            экраны (Expo Router): _layout (стек), (tabs)/ index (карта), list (рядом), settings,
                    new (новая заметка), note/[id] (карточка и редактирование), import (подтверждение импорта)
src/components/     NotesMap (.native — Leaflet/OpenStreetMap в WebView, без суффикса — web), NoteForm, ProximityBanner,
                    LocationNotice, кнопки, диалоги, обмен, тема
src/context/        NotesContext: заметки, настройки, слежение за позицией, срабатывания
src/lib/            geo (haversine, nearbyTriggers, геозоны), share (ссылки, base64url, слияние), mapHtml (страница карты),
                    notifications, background (фоновая задача геозон), storage, types
scripts/test.mjs    тесты на node:test
```

## Ограничения

- iOS следит максимум за 20 геозонами на приложение, поэтому в фоне работают 20 ближайших заметок.
  Список обновляется при каждом открытии приложения.
- Фоновые геозоны срабатывают с задержкой и точностью, которые выбирает система (обычно 100 м и больше).
  Для радиуса 50 м фоновое напоминание может прийти позже или не прийти.
- В Expo Go на Android expo-notifications может писать в консоль предупреждение про push-уведомления. Локальные уведомления
  работают.
- Длинная ссылка со многими заметками может не поместиться в некоторые мессенджеры. Тогда делитесь заметками по одной.
