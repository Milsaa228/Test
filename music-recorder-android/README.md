# Music Recorder для Android

Приложение для Android 10+, которое:

- **записывает звук, который играет на телефоне** (из плеера, браузера, игр), в файл `.m4a` (AAC, 192 кбит/с). Записи сохраняются в общую папку `Music/MusicRecorder` и видны любому плееру. Файл называется по треку, который играл в момент старта записи;
- **фиксирует трек, который сейчас играет**: исполнитель, название, альбом, приложение и время. Список хранится в приложении, его можно отправить в виде CSV в мессенджер или почту. Долгое нажатие на трек открывает его поиск в интернете.

> Записывайте только то, на что у вас есть права. Android даёт приложениям-плеерам запретить захват своего звука, и многие стриминговые сервисы так и делают. Из таких приложений запись будет пустой, приложение этот запрет не обходит. «Зафиксировать трек» работает с любым плеером.

## Сохранение из шторки уведомлений

Приложение не нужно открывать, чтобы сохранить трек:

- **Плашка «Сейчас играет».** Пока в любом плеере есть трек, в шторке висит уведомление с его названием и кнопками **☆ Зафиксировать трек** и **● Записать**. При смене трека плашка обновляется сама. Повторное нажатие на тот же трек не создаёт дубль: в плашке появится «✓ Трек в списке». Плашку можно выключить переключателем на главном экране.
- **Плитка в быстрых настройках.** Опустите шторку полностью, нажмите карандаш (редактирование плиток) и перетащите плитку **«Зафиксировать трек»** наверх. Нажатие на неё сохраняет играющий трек, а подпись под плиткой показывает, что сейчас играет.
- **Во время записи** в уведомлении о записи тоже есть кнопка **☆ Зафиксировать трек**.

Плашке и плитке нужен тот же доступ к уведомлениям, что и кнопке в приложении. На Android 13+ нужно ещё разрешение на показ уведомлений: приложение спросит его при запуске.

Кнопка «Записать» в шторке открывает приложение. Разрешение на захват звука Android может спросить только из открытого приложения.

## Как установить APK

1. Откройте на телефоне страницу релиза **music-recorder-latest** в репозитории (раздел *Releases*) и скачайте `MusicRecorder.apk`.
   APK также есть в артефактах каждой сборки во вкладке *Actions → Music Recorder APK*, там он лежит в zip-архиве.
2. Откройте файл. Если Android спросит, разрешите установку из этого источника (браузера или файлового менеджера).
3. Если Google Play Защита предупредит о неизвестном разработчике, нажмите «Всё равно установить». Приложение подписано отладочным ключом, а не ключом магазина.

## Первый запуск

- **Запись.** Нажмите **● Записать** и разрешите запись звука и уведомления. В системном окне захвата выберите «Весь экран» (Android 14+) и нажмите «Начать». Пока идёт запись, в шторке висит уведомление с таймером и кнопкой «Остановить».
- **Фиксация трека.** Нажмите **Дать доступ к уведомлениям** и включите Music Recorder в списке. Без этого доступа Android не показывает приложениям, что играет в других плеерах. Содержимое уведомлений приложение не читает.

## Сборка из исходников

APK собирает GitHub Actions (`.github/workflows/music-recorder-apk.yml`) при каждом изменении папки `music-recorder-android/`. Локально нужны JDK 17 и Android SDK (API 35):

```bash
cd music-recorder-android
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Можно открыть папку в Android Studio и запустить на устройстве кнопкой Run.

## Как устроено

| Файл | Роль |
|---|---|
| `MainActivity.kt` | Экран: текущий трек, запись с таймером, список сохранённых треков |
| `RecordService.kt` | Foreground-сервис типа `mediaProjection`: получает разрешение на захват, запускает запись, сохраняет файл через MediaStore |
| `AudioCapture.kt` | `AudioPlaybackCapture` → `AudioRecord` (PCM 44.1 кГц, стерео) → `MediaCodec` AAC → `MediaMuxer` (.m4a) |
| `Tracks.kt` | Текущий трек через `MediaSessionManager`, хранение списка в SharedPreferences, экспорт CSV |
| `MediaListener.kt` | `NotificationListenerService`: даёт доступ к медиасессиям и следит за сменой трека, чтобы обновлять плашку |
| `TrayNotification.kt` | Плашка «Сейчас играет» с кнопками, общая логика сохранения трека, `SaveTrackReceiver` для кнопки в шторке |
| `SaveTrackTile.kt` | Плитка «Зафиксировать трек» в быстрых настройках |

Без сторонних библиотек: только Android SDK и Kotlin. `minSdk 29`, `targetSdk 35`.
