# Soundwave

Мобильный музыкальный плеер в духе Spotify (Expo / React Native, iOS и Android; работает и в браузере).
Встроенная музыка играет без интернета, а новую можно найти и скачать из интернета.

## Возможности

- **Встроенная музыка без интернета**: 12 треков Kevin MacLeod (incompetech.com) в разных жанрах: лаунж, джаз, классика, электроника, рок, фанк, фолк, чиптюн, эмбиент. Файлы лежат внутри приложения (`assets/music`, MP3 96 кбит/с, ~28 МБ).
- **Музыка из интернета** (вкладка «Поиск» → «В интернете»): поиск свободной музыки в [Internet Archive](https://archive.org) без ключей API. Альбом можно послушать потоком, сохранить в «Мои треки» или скачать на телефон, и тогда треки играют офлайн. Лицензия каждой записи показана на экране альбома и в плеере.
- **Трек по ссылке**: вставьте прямую ссылку на MP3, M4A, OGG и т. п. в поиск или нажмите «Медиатека» → «Добавить по ссылке». Приложение скачает файл, а в браузере сохранит его как поток.
- **Свои файлы** с телефона: «Медиатека» → «Добавить музыку с устройства». Исполнитель и название берутся из имени файла `Исполнитель - Название.mp3`.
- **Главная**: подборки, «Недавно прослушанные», жанры, исполнители.
- **Медиатека**: «Любимые треки», свои плейлисты (создать, переименовать, удалить), «Мои треки».
- **Плеер**: перемотка, перемешивание, повтор (выкл. / очередь / один трек), лайк, мини-плеер, очередь, «Играть следующим».
- **Фоновое воспроизведение** и управление с экрана блокировки (`expo-audio`).
- Всё хранится на устройстве: лайки, плейлисты, история, скачанные файлы, режимы плеера.

## Музыка и лицензии

- Встроенные треки — Kevin MacLeod (incompetech.com), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Авторство указано в приложении: «Медиатека» → ⓘ и внизу главной. Список файлов с исходными ссылками — `assets/music/manifest.json`.
- Файлы скачал workflow `.github/workflows/soundwave-fetch-music.yml`: он берёт их с incompetech.com и пережимает в 96 кбит/с. Чтобы заменить набор, поправьте список в workflow, запустите его и обновите `src/lib/catalog.ts` и `src/lib/musicAssets.ts`. Тест сверяет их с manifest.
- У музыки из Internet Archive лицензии разные. Скачивайте только то, что разрешено.

## Запуск

```bash
npm install
npx expo start          # Expo Go (QR-код), эмулятор или браузер (клавиша w)
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: очередь, библиотека, поиск, каталог, разбор Internet Archive
```

Фоновое воспроизведение и экран блокировки полноценно работают в сборке приложения, а не в Expo Go.

## APK для Android

APK собирает GitHub Actions (`.github/workflows/soundwave-apk.yml`) при каждом пуше с изменениями в `soundwave/`, а также вручную
(Actions → «soundwave APK» → Run workflow). Готовый файл появляется в разделе **Releases** репозитория (`soundwave-build-<номер>`)
и в артефактах запуска. Сборка подписана debug-ключом: её можно ставить на телефон напрямую, но для Google Play нужен свой ключ.

Локально: `npx expo prebuild -p android && cd android && ./gradlew assembleRelease` (нужны Android SDK и JDK 17),
или в облаке Expo: `npx eas-cli@latest build -p android --profile preview`.

## Структура

```
src/app/              экраны (Expo Router)
  _layout.tsx         корневой стек и провайдеры
  (tabs)/             вкладки: index (главная), search, library + мини-плеер над таб-баром
  collection/[id].tsx плейлист / альбом / исполнитель / жанр / любимые / файлы
  player.tsx          полноэкранный плеер
  queue.tsx           очередь
  net/[id].tsx        альбом из Internet Archive: слушать, сохранить, скачать
  credits.tsx         авторы встроенной музыки
src/components/       Cover, TrackRow, MiniPlayer, ProgressBar, Sheet, NamePrompt, Shelf, Icon, тема
src/context/          LibraryContext (медиатека, импорт файлов), PlayerContext (expo-audio + очередь),
                      TrackMenuContext (меню трека, добавление в плейлист, уведомления)
src/lib/              queue (очередь, перемешивание, повтор), library (reducer, коллекции, поиск),
                      catalog (встроенный каталог), musicAssets (require встроенных MP3),
                      archive (поиск и разбор Internet Archive), storage, types
assets/music/         встроенные MP3 + manifest.json
scripts/test.mjs      тесты на node:test
```

Адрес коллекции — `collection/<id>`, где id: `liked`, `local`, `pl:<id>`, `album:<исполнитель>::<альбом>`, `artist:<имя>`, `genre:<жанр>`.
