# Soundwave

Мобильный музыкальный плеер в духе Spotify / Яндекс Музыки (Expo / React Native, iOS и Android; работает и в браузере).
Вся музыка берётся из интернета, из [Internet Archive](https://archive.org), и только со свободными лицензиями. Рекомендации считаются прямо на телефоне.

## Возможности

- **Первый запуск**: экран «Что вы любите слушать?». 38 жанров и исполнители круглыми фото. Исполнителя можно найти поиском, в том числе по-русски («моцарт» → Mozart), или вписать своего. Изменить выбор можно в настройках.
- **Моя волна**: бесконечный поток музыки, похожей на любимую. Очередь сама подгружается, когда подходит к концу. Кнопка 👎 «Не нравится» убирает трек из рекомендаций. Без интернета волна собирается из скачанных треков.
- **Миксы дня, недели и месяца**: обновляются каждый день, по понедельникам и 1-го числа. В течение периода микс не меняется и хранится на телефоне. Микс можно сохранить в медиатеку как плейлист.
  - **Правило**: понравившиеся треки в миксы почти не попадают. Лайки служат «семенами» для поиска похожего. Если свежих треков хватает, лайкнутых в миксе нет совсем, иначе их не больше 10%. Правило закреплено в `AGENTS.md` и тестом.
- **Главная**: «Моя волна», миксы, полки «Для вас» по выбранным жанрам и исполнителям, «Недавно прослушанные».
- **Поиск** в медиатеке и в интернете (Internet Archive); можно также вставить прямую ссылку на аудиофайл. Запрос разбирается:
  - кириллица ↔ латиница: «kino» → «кино», «эминем» → eminem;
  - неверная раскладка: «vjwfhn» → «моцарт»;
  - русские написания иностранных имён: «металлика» → Metallica, около 100 имён;
  - опечатки.

  Есть история запросов.
- **Плейлист по треку и по исполнителю**: кнопка «Похожие» в плеере, меню трека, страница исполнителя. В плейлист попадает сам исполнитель и музыка близких жанров; его можно сохранить в медиатеку.
- **Страница исполнителя**: фото, кнопка «Любимый исполнитель» (учитывается в рекомендациях), его треки в медиатеке и записи в архиве.
- **Текст песни** из LRCLIB: синхронизированный с подсветкой строки и перемоткой по нажатию на строку, либо обычный.
- **Таймер сна**: через 15, 30, 45, 60 или 90 минут либо в конце трека.
- **Медиатека**: «Любимые треки», «Мои треки» (сохранённые и скачанные), свои плейлисты, импорт файлов с телефона.
- **Настройки**:
  - офлайн-режим: играют только скачанные треки; включается и сам, если пропала сеть;
  - автоскачивание понравившихся;
  - «Скачать все понравившиеся»;
  - объём загрузок и их удаление;
  - мои предпочтения, «Обновить миксы», очистка истории.
- **Плеер**: перемотка, перемешивание, повтор, очередь, «Играть следующим», фоновое воспроизведение, экран блокировки.

## Как работают рекомендации

1. **Профиль вкуса** (`src/lib/recommend.ts`). В нём складываются веса исполнителей и жанров:
   - стартовые предпочтения;
   - лайки;
   - прослушивания, у которых вес со временем затухает;
   - пропуски: переключение в первые 30 секунд;
   - «не нравится».

   Жанр трека определяется по темам (`subject`) записи в архиве.
2. **«Семена»**: несколько исполнителей и жанров, выбранных с учётом весов. Жанров не меньше половины, чтобы находились новые исполнители.
3. **Кандидаты** (`src/lib/reco.ts`): по каждому семени ищутся записи в архиве, из каждой берётся пара треков длиной от 1 до 15 минут.
4. **Сборка** (`assembleMix`):
   - в приоритете новые треки, недавно прослушанные идут в последнюю очередь;
   - от одного исполнителя не больше двух треков, и один исполнитель не звучит два раза подряд;
   - лайкнутые добавляются только для заполнения, не больше 10%.

   Случайность в миксах детерминирована ключом периода, поэтому весь день микс один и тот же.

Проверка на живом archive.org: workflow `.github/workflows/soundwave-live-check.yml` запускает `scripts/live-check.mjs`. Скрипт собирает настоящие миксы и волну кодом приложения и проверяет, что каждый жанр и исполнитель стартового экрана находит музыку.

## Музыка и лицензии

- Показываются только записи с `licenseurl` Creative Commons или в общественном достоянии. Аудиокниги, подкасты и прочие речевые записи исключены (`MUSIC_FILTER` в `src/lib/archive.ts`).
- Лицензия и ссылка на страницу записи видны в плеере и на экране альбома. Условия у лицензий разные: например, CC BY требует указывать автора, NC запрещает коммерческое использование.

## Запуск

```bash
npm install
npx expo start          # Expo Go (QR-код), эмулятор или браузер (клавиша w)
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты: очередь, медиатека, Internet Archive, рекомендации и правило миксов
```

## APK для Android

APK собирает GitHub Actions (`.github/workflows/soundwave-apk.yml`) при каждом пуше с изменениями в `soundwave/`; запустить его можно и вручную. Готовый файл появляется в разделе **Releases** (`soundwave-build-<номер>`). Сборка подписана debug-ключом: её можно ставить на телефон напрямую, но для Google Play нужен свой ключ.

## Структура

```
src/app/              экраны (Expo Router)
  _layout.tsx         корневой стек и провайдеры
  onboarding.tsx      выбор жанров и исполнителей
  (tabs)/             главная, поиск, медиатека + мини-плеер над таб-баром
  collection/[id].tsx плейлист / любимые / мои треки / исполнитель / микс (mix:day|week|month)
  net/[id].tsx        запись Internet Archive: слушать, сохранить, скачать
  artist/[name].tsx   страница исполнителя;  radio/[id].tsx — плейлист по треку / исполнителю
  player.tsx, queue.tsx, lyrics.tsx, settings.tsx, credits.tsx
src/components/       Cover, TrackRow, MiniPlayer, ProgressBar, NetShelf, Shelf, Sheet, NamePrompt, Icon, тема
src/context/          LibraryContext (медиатека, загрузки, сеть, настройки), PlayerContext (expo-audio + очередь),
                      RecoContext (миксы, волна, полки), TrackMenuContext (меню трека, уведомления)
src/lib/              archive (Internet Archive), genres (жанры и исполнители), recommend (профиль вкуса, сборка миксов),
                      reco (кандидаты, миксы, волна, плейлист по треку/исполнителю), textq (разбор запроса: транслит, раскладка, словарь),
                      lyrics (LRCLIB), images (фото исполнителей из Deezer), library, queue, cache, storage, types
scripts/test.mjs      тесты на node:test;  scripts/live-check.mjs — проверка на живом archive.org
```
