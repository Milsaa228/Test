# Soundwave

Мобильный музыкальный плеер в духе Spotify (Expo / React Native, iOS и Android; работает и в браузере).

## Возможности

- **Главная**: быстрый доступ к любимым и подборкам, «Недавно прослушанные», подборки, альбомы, исполнители.
- **Поиск** по названию, исполнителю и альбому (регистр и «ё» не важны) и плитки жанров.
- **Медиатека**: «Любимые треки», свои плейлисты (создать, переименовать, удалить, убрать трек) и файлы с устройства.
- **Плеер**: полноэкранный экран с перемоткой, перемешиванием, повтором (выкл. / очередь / один трек) и лайком. Мини-плеер над вкладками и на экранах плейлистов.
- **Очередь**: что играет сейчас и дальше, переход к любому треку, удаление из очереди, «Играть следующим» из меню трека.
- **Фоновое воспроизведение** и управление с экрана блокировки (`expo-audio`).
- **Свои треки**: «Медиатека» → «Добавить музыку с устройства». Файлы копируются в папку приложения, исполнитель и название берутся из имени файла `Исполнитель - Название.mp3`.
- Всё хранится на устройстве (AsyncStorage): лайки, плейлисты, история, режимы плеера и последний трек.

Демо-каталог — 16 треков с [soundhelix.com](https://www.soundhelix.com/audio-examples) (сгенерированная музыка, свободные примеры). Для них нужен интернет. Названия, исполнители и подборки придуманы для демо. Обложки рисуются градиентами, без загрузки картинок.

## Запуск

```bash
npm install
npx expo start          # Expo Go (QR-код), эмулятор или браузер (клавиша w)
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: очередь, повтор/перемешивание, библиотека, поиск
```

Фоновое воспроизведение и экран блокировки полноценно работают в сборке приложения, а не в Expo Go.

## APK для Android

APK собирает GitHub Actions (`.github/workflows/soundwave-apk.yml`) при каждом пуше с изменениями в `soundwave/`, а также вручную
(Actions → «soundwave APK» → Run workflow). Готовый файл появляется в разделе **Releases** репозитория (`soundwave-build-<номер>`)
и в артефактах запуска. Сборка подписана debug-ключом: её можно ставить на телефон напрямую, но для Google Play нужен свой ключ.

Локально: `npx expo prebuild -p android && cd android && ./gradlew assembleRelease` (нужны Android SDK и JDK 17),
или в облаке Expo: `npx eas-cli@latest build -p android --profile preview`.

## Структура

```
src/app/              экраны (Expo Router)
  _layout.tsx         корневой стек и провайдеры
  (tabs)/             вкладки: index (главная), search, library + мини-плеер над таб-баром
  collection/[id].tsx плейлист / альбом / исполнитель / жанр / любимые / файлы
  player.tsx          полноэкранный плеер
  queue.tsx           очередь
src/components/       Cover, TrackRow, MiniPlayer, ProgressBar, Sheet, NamePrompt, Shelf, Icon, тема
src/context/          LibraryContext (медиатека, импорт файлов), PlayerContext (expo-audio + очередь),
                      TrackMenuContext (меню трека, добавление в плейлист, уведомления)
src/lib/              queue (очередь, перемешивание, повтор), library (reducer, коллекции, поиск),
                      catalog (демо-каталог), storage, types
scripts/test.mjs      тесты на node:test
```

Адрес коллекции — `collection/<id>`, где id: `liked`, `local`, `pl:<id>`, `album:<исполнитель>::<альбом>`, `artist:<имя>`, `genre:<жанр>`.
