# Делёжка счёта

Мобильное приложение (Expo / React Native, Android) для дележа счёта в кафе. Фотографируете чек, бесплатная
нейросеть разбирает позиции, вы отмечаете, кто что ел, и отправляете друзьям, сколько кто должен.

## Как пользоваться

1. В «Настройках» (⚙️) вставьте бесплатный ключ OpenRouter (openrouter.ai → Keys → Create key, можно прямо с телефона), своё имя и телефон для СБП.
2. «Сфотографировать чек» или «Выбрать фото». Нейросеть вернёт позиции, итог и сервисный сбор. Можно ввести счёт и вручную.
3. Добавьте друзей и нажмите на того, кто платил (💳).
4. У каждой позиции отметьте, кто её ел. Если никто не отмечен, позиция делится на всех.
5. «Отправить друзьям» откроет системное меню «Поделиться» с готовым текстом: суммы и куда переводить.

## Возможности

- Распознавание чеков: построчные суммы, количество, скидки, сервисный сбор, итог по чеку.
- Сверка с итогом чека: если сумма позиций не сходится, приложение предупредит.
- Деление в копейках без потерь: сумма долей всегда равна итогу, лишние копейки распределяются по наибольшему остатку.
- Чаевые 0/5/10/15 % (или процент из чека) делятся пропорционально тому, кто сколько съел.
- История счетов на устройстве.

## Запуск

```bash
npm install
npx expo start          # Expo Go (QR-код) или эмулятор
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: деление, чаевые, разбор ответа модели, запросы к API (с моком fetch)
```

## Структура

```
src/app/            экраны (Expo Router): index (счета + новый счёт), bill/[id] (редактор счёта), settings
src/components/     тема, кнопки, notify/confirm
src/context/        BillsContext: счета, настройки, ключ
src/lib/            ai (клиент бесплатных моделей), receipt (промпт и схема распознавания чека),
                    split (деление, форматирование, текст сообщения), photo (камера и сжатие), storage
scripts/test.mjs    тесты на node:test
```

## Нейросеть

- По умолчанию используются бесплатные модели OpenRouter. Приложение само выбирает из каталога бесплатную модель,
  которая понимает фото. Если она перегружена или ответила мусором, пробует следующую.
- Лимиты бесплатного ключа: около 20 запросов в минуту и 50 в день на аккаунт. Для чеков с друзьями этого с запасом.
- Бесплатные модели слабее платных: проверяйте позиции после распознавания. Ответ разбирается терпимо: числа строкой,
  пояснения вокруг JSON и лишние поля не ломают приложение.
- Фото перед отправкой уменьшается до 1568 px по длинной стороне и сжимается в JPEG.
- Ключ хранится в Keychain/Keystore (expo-secure-store), запросы идут с телефона напрямую в API.
- «Для продвинутых» в настройках: можно указать любой OpenAI-совместимый API и модель.
