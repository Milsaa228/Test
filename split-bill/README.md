# Делёжка счёта

Мобильное приложение (Expo / React Native, iOS и Android) для дележа счёта в кафе. Фотографируете чек, Claude
разбирает позиции, вы отмечаете, кто что ел, и отправляете друзьям, сколько кто должен.

## Как пользоваться

1. В «Настройках» (⚙️) вставьте ключ Claude API (console.anthropic.com → API Keys), своё имя и телефон для СБП.
2. «Сфотографировать чек» или «Выбрать фото». Claude вернёт позиции, итог и сервисный сбор. Можно ввести счёт и вручную.
3. Добавьте друзей и нажмите на того, кто платил (💳).
4. У каждой позиции отметьте, кто её ел. Если никто не отмечен, позиция делится на всех.
5. «Отправить друзьям» откроет системное меню «Поделиться» с готовым текстом: суммы и куда переводить.

## Возможности

- Распознавание чеков: построчные суммы, количество, скидки, сервисный сбор, итог по чеку.
- Сверка с итогом чека: если сумма позиций не сходится, приложение предупредит.
- Деление в копейках без потерь: сумма долей всегда равна итогу, лишние копейки распределяются по наибольшему остатку.
- Чаевые 0/5/10/15 % (или процент из чека) делятся пропорционально тому, кто сколько съел.
- История счетов на устройстве.

## Запуск

```bash
npm install
npx expo start          # Expo Go (QR-код) или эмулятор
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: деление, чаевые, разбор ответа модели, запрос к Claude API (с моком fetch)
```

## Структура

```
src/app/            экраны (Expo Router): index (счета + новый счёт), bill/[id] (редактор счёта), settings
src/components/     тема, кнопки, notify/confirm
src/context/        BillsContext: счета, настройки, ключ
src/lib/            claude (клиент Claude API), receipt (промпт и схема распознавания чека),
                    split (деление, форматирование, текст сообщения), photo (камера и сжатие), storage
scripts/test.mjs    тесты на node:test
```

## Замечания про Claude API

- Модель `claude-opus-5-5`, ответ строго по JSON-схеме (structured outputs). Включён серверный fallback: если модель
  отклонит запрос, он автоматически повторится на запасной модели.
- Фото перед отправкой уменьшается до 1568 px по длинной стороне и сжимается в JPEG. Так запрос быстрее и дешевле,
  а качество распознавания не страдает.
- Ключ хранится в Keychain/Keystore (expo-secure-store), запросы идут с телефона напрямую на `api.anthropic.com`.
  Для своего пользования этого достаточно. Если публиковать приложение для других, ключ нужно убрать на свой
  бэкенд-прокси. На web ключ не сохраняется между перезагрузками страницы.
