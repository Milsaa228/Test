# Tab Audio Recorder

Расширение для браузера (Chrome / Edge / Яндекс Браузер и другие на Chromium) с двумя функциями:

- **Запись звука вкладки.** Пишет всё, что звучит во вкладке, в файл `.webm` (Opus, 192 кбит/с) и сохраняет его в папку загрузок `TabRecorder/`. Пока идёт запись, звук продолжает играть, а на значке расширения горит `REC`.
- **«Зафиксировать трек».** Сохраняет исполнителя, название, альбом и ссылку на то, что сейчас играет. Данные берутся из Media Session API, который заполняет большинство музыкальных сайтов, а если его нет — из заголовка вкладки. Список можно выгрузить в CSV.

> Записывайте только то, на что у вас есть права: свой контент, музыку под свободными лицензиями, личные эфиры и т.п. Условия многих стриминговых сервисов запрещают сохранять их музыку. Расширение не обходит DRM: оно пишет только то, что вкладка отдаёт как обычный звук.

## Установка на компьютере

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `tab-audio-recorder`.
4. Закрепите значок расширения на панели.

Нужен Chrome 116 или новее.

## Использование

1. Откройте вкладку с плеером и включите воспроизведение.
2. Нажмите на значок расширения и затем **● Записать**.
3. Нажмите **■ Остановить**: файл сохранится в загрузки. Если закрыть вкладку, запись тоже остановится и сохранится.
4. **☆ Зафиксировать трек** добавляет текущий трек в список. **CSV** выгружает список, **Очистить** удаляет его.

Файлы `.webm` воспроизводят браузеры, VLC и большинство плееров. Чтобы получить MP3, конвертируйте файл:
`ffmpeg -i запись.webm -b:a 192k запись.mp3`.

## Установка на Android

Мобильный Chrome расширения не поддерживает, но некоторые браузеры на Chromium для Android умеют их ставить: Яндекс Браузер, Lemur Browser, Quetta, Microsoft Edge (Canary/Dev). Порядок установки зависит от браузера. Обычно нужно включить режим разработчика на странице расширений (`chrome://extensions` или аналог) и загрузить расширение из `.zip` или `.crx`. Чтобы собрать архив, запакуйте содержимое папки `tab-audio-recorder`, чтобы `manifest.json` оказался в корне архива.

Ограничения на Android:

- **«Зафиксировать трек» и список треков** должны работать в любом браузере, где ставятся расширения.
- **Запись звука** использует API `tabCapture` и `offscreen`, а мобильные браузеры их обычно не поддерживают. Скорее всего, кнопка записи покажет ошибку. На Android надёжнее записывать звук встроенной записью экрана с опцией «звук устройства».
- Firefox для Android поддерживает расширения только в собственном формате и без `tabCapture`, поэтому это расширение в нём не заработает.

На Android расширение не тестировалось. Поддержка расширений в мобильных браузерах часто меняется.

## Как устроено

| Файл | Роль |
|---|---|
| `manifest.json` | Manifest V3, разрешения: `tabCapture`, `offscreen`, `downloads`, `storage`, `scripting`, `activeTab` |
| `popup.*` | Интерфейс. Получает `streamId` вкладки (это требует клика пользователя) и читает метаданные трека |
| `background.js` | Сервис-воркер: создаёт offscreen-документ, хранит состояние записи, сохраняет файл через `chrome.downloads` |
| `offscreen.*` | Получает поток вкладки, пишет его через `MediaRecorder` и проигрывает обратно через `AudioContext`, потому что `tabCapture` глушит вкладку |
