# Расходы Т-Банк

Мобильное приложение (Expo / React Native, iOS и Android) для статистики расходов по данным Т-Банка.

## Источники данных

| Источник | Для кого | Как подключить |
|---|---|---|
| **CSV-выписка** | Личные карты и счета | В приложении Т-Банка или на tbank.ru: «Операции» → период → «Выписка» → CSV. Потом на вкладке «Источники» нажмите «Импортировать CSV». |
| **Т-Бизнес Open API** | Счета ИП и юрлиц | Выпустите токен в Т-Бизнесе («Интеграции» → «Т-API», право на выписку), вставьте на вкладке «Источники», выберите счёт и период. |
| **Демо-данные** | Посмотреть, как всё выглядит | Кнопка «Загрузить демо-данные». |

> У Т-Банка нет публичного API для операций по личным картам: официальный Open API есть только у Т-Бизнеса.
> Поэтому личные расходы загружаются из CSV-выписки. Повторный импорт того же периода не создаёт дублей.

## Возможности

- Расходы и доходы за месяц, сравнение с прошлым месяцем, средний расход в день.
- Кольцевая диаграмма и список категорий с долями. Нажатие на категорию открывает её операции.
- Графики расходов по дням и динамика за 6 месяцев. Нажатие на столбик открывает этот месяц.
- Топ мест, где тратится больше всего.
- Лента операций с группировкой по дням, поиском и фильтром по категориям.
- Переключатель «Учитывать переводы». По умолчанию исходящие переводы не считаются тратами.
- Категория по MCC, если банк её не прислал.
- **«Двойник»**: прогноз расходов на конец месяца, сколько дней до зарплаты и сколько уйдёт до неё,
  найденные подписки и регулярные платежи с датой следующего списания.
- Чат с Claude о своих финансах: «Могу ли я позволить себе отпуск в марте за 100 000 ₽?», «Где я переплачиваю?»,
  «Составь бюджет на следующий месяц». История чата сохраняется, кнопка «Новый разговор» начинает заново.
- Данные хранятся только на устройстве: операции и история чата в AsyncStorage, токен и ключ Claude в Keychain/Keystore (expo-secure-store).

## Запуск

```bash
npm install
npx expo start          # открыть в Expo Go (QR-код) или в эмуляторе
npm run typecheck       # проверка типов
npx expo lint           # линтер
npm test                # тесты логики: парсер CSV, кодировки, статистика, маппинг API, прогноз, сводка для Claude
```

Сборка для установки на телефон: `npx eas-cli@latest build -p android --profile preview` (или `-p ios`).

```

src/components/     графики (DonutChart, BarChart), MonthSwitcher, тема

                    stats (агрегации), categories (MCC, цвета), storage, demo,
                    forecast (прогноз, подписки, зарплата), finContext (сводка для Claude), claude (клиент Claude API)
scripts/test.mjs    тесты на node:test
```

## Замечания по API

Клиент `src/lib/tbankApi.ts` обращается к `GET /api/v4/bank-accounts` и `GET /api/v1/statement`
(`accountNumber`, `from`, `to`, `cursor`) на `https://business.tbank.ru/openapi` с заголовком `Authorization: Bearer <токен>`.
Ответ разбирается с запасом: поддерживаются несколько вариантов названий полей.
Перед первым запуском с реальным токеном сверьте схему с документацией https://developer.tbank.ru/docs/api.
В web-версии запросы к API заблокирует CORS. Используйте iOS или Android.

## «Двойник» и Claude API

Прогноз и поиск подписок считаются на устройстве (`src/lib/forecast.ts`), без сети:

- **Прогноз на конец месяца** = уже потрачено + обычный расход в день × оставшиеся дни + ожидаемые списания подписок.
  Обычный расход в день — среднее за последние 90 дней без подписок и без разовых крупных покупок
  (от 15 000 ₽ и в 10 раз больше типичной операции).
- **Подписка** — один получатель, сумма ±15%, не меньше 3 списаний с интервалом 25–35 дней.
  Если списание просрочено больше чем на неделю, подписка считается отменённой.
- **Зарплата** — самое крупное регулярное поступление (не меньше 2 выплат с интервалом 10–40 дней).

Для чата нужен свой ключ Claude API (console.anthropic.com), его вводят на вкладке «Источники».

> Ключ хранится только на устройстве (Keychain/Keystore). В web-версии — только в памяти до перезагрузки страницы.
> Запросы идут напрямую с телефона на `api.anthropic.com`, без промежуточного сервера.
> В контекст модели уходит сводка, а не вся выписка: итоги по месяцам и категориям за 6 месяцев, топ мест,
> источники доходов, подписки, прогноз и не больше 200 крупнейших операций (дата, категория, описание, сумма).
> Сводка передаётся в системном промпте с кэшированием, поэтому повторные вопросы в разговоре дешевле.
